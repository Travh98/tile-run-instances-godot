# Tile Run Instances
Tiles multiple instances of the game nicely across your monitor.

## Setup
1. Clone this repo
2. Move tile-run-instances into the addons/ folder of your Godot project.
3. Enable tile-run-instances in the Project Settings > Plugins tab
4. Add TileRunInstancesGlobal as a Global Autoload in Project Settings > Globals
5. Enable multiple instances in Debug > Customize Run Instances

## Tips
- Need your windows to show up on a different monitor? Edit the `target_monitor` variable of tile_run_instances_global.gd
